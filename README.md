# Personal Portfolio Website

A clean personal portfolio website built with HTML, CSS and JavaScript.

## Features

- Responsive hero section with a clear introduction and call to action
- About, Skills, Projects and Contact sections
- Clean, modern design that works on desktop, tablet and mobile
- Smooth scrolling navigation and a mobile-friendly menu
- Project cards with links, so new work can be added easily
- Simple contact section for reaching out

## Tech Stack

- HTML5 — structure and content
- CSS3 — layout, responsive design and styling
- JavaScript — navigation, interactivity and small UI effects
- No build tools or frameworks required

## How to Run / Usage

1. Clone the repository:

   ```bash
   git clone https://github.com/UUUU41/personal-portfolio-website.git
   cd personal-portfolio-website
   ```

2. Open `index.html` in any modern web browser, or serve the folder with a simple static server:

   ```bash
   python3 -m http.server 8000
   ```

   Then visit `http://localhost:8000`.

3. Edit the text in `index.html` and the colours and layout in `style.css` to make it your own.
